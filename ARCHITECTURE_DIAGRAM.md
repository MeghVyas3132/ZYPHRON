Setup Process:
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│  1. Run: ./scripts/setup-ssl.sh                            │
│         (uses Certbot & Let's Encrypt)                      │
│          ↓                                                   │
│  2. Certbot requests certificates for:                     │
│     • yourdomain.com                                       │
│     • *.yourdomain.com (wildcard)                          │
│     • www.yourdomain.com                                   │
│          ↓                                                   │
│  3. Let's Encrypt validates ownership                      │
│     (creates temporary files for verification)             │
│          ↓                                                   │
│  4. Certificates issued & stored in:                       │
│     infrastructure/certs/live/yourdomain.com/              │
│     ├── fullchain.pem                                      │
│     └── privkey.pem                                        │
│          ↓                                                   │
│  5. Nginx loads certificates on startup                    │
│     & serves HTTPS on port 443                             │
│          ↓                                                   │
│  6. HTTP traffic (port 80) redirects to HTTPS             │
│                                                              │
└─────────────────────────────────────────────────────────────┘

Certificate Lifecycle:
┌─────────────────────────────────────────────────────────────┐
│ Issued              │ Expires              │ Renew by        │
├─────────────────────────────────────────────────────────────┤
│ Day 0               │ Day 90               │ Day 60          │
│                     │                      │                 │
│ ←──────── Certificate Valid (90 days) ──────→              │
│         (recommended renew 30 days before expiry)           │
└─────────────────────────────────────────────────────────────┘

Renewal Command:
  certbot renew
  OR
  ./scripts/setup-ssl.sh
